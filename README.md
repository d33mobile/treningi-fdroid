# Treningi: F-Droid repository

F-Droid repository of Treningi (`pl.d33.treningi`), the Android app of the workout log at
https://treningi.ai.d33.pl: the site full screen in Chrome (Trusted Web Activity), a home-screen
widget and a rest alarm that rings on the lock screen. Using it needs an account on that site.

## Add this repository

Open the [landing page](https://d33mobile.github.io/treningi-fdroid/) on the phone and tap
"Dodaj repozytorium do F-Droid", or in the F-Droid client: Settings > Repositories > +, then scan
the QR code or paste the address with the fingerprint from the landing page:

    https://d33mobile.github.io/treningi-fdroid/repo?fingerprint=c2ab085e8fb77f572b39363294e4235aed34d3cac2aae4914488a00d218657a0

## Contents

GitHub Pages serves this branch from the root. `repo/` holds the signed F-Droid index, the APKs and
the icons; `index.html` is the landing page. Everything here is generated by the release script of
the app; changes made by hand are overwritten by the next release.
